# Threads

> Every planted question, mystery, promise, or Chekhov's gun, tracked so
> none get silently dropped. `status` is one of `open` / `resolved` /
> `abandoned` — abandoned is a valid, honest outcome, better than a thread
> that just quietly vanishes. A thread still `open` when the manuscript
> ends is worth a second look before you call the book done.
>
> The trailing `kind` column types a thread as a *promise to the reader*.
> Leave it empty for a plain plot thread. Set it to one of `mystery`
> (a question the reader wants answered), `threat` (a danger that must be
> discharged), `want` (a character desire that must be satisfied or denied),
> or `image` (a planted picture or line meant to pay off later). A promise
> row still `open` at the end is an unfired gun — run `stoner promises check`.
